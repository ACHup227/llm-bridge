# llm-bridge

Provider-agnostic LLM port for subscription-first CLI/SDK backends (Claude Code CLI, Codex CLI, Vertex Gemini), shared across `tldr-filter`, `hots_replay_coach`, `groceries`, `meeting-summerizer` and `video_summarizer` so each project stops hand-rolling its own adapter. Callers depend only on the `LLMClient` Protocol in `port.py`; `make_llm()` picks the concrete adapter from the `LLM_PROVIDER` env var (`claude-cli` default, `codex-cli`, or `vertex-gemini` — the last requires `GOOGLE_CLOUD_PROJECT` and is never a silent default) and `LLM_MODEL` overrides the adapter's own default model when set — but only when a call site passes `model=None`; an explicit `model=` argument on `complete()`/`complete_json()` always wins over `LLM_MODEL`. **Migration contract**: introducing this package changes no caller's behaviour by itself — every existing call site keeps naming its own model explicitly (`model="claude-opus-4-8"`, `model="sonnet"`, ...) rather than falling onto the bridge's package-level default, so a project only moves onto a new default model through its own deliberate edit, never as a side effect of adopting `llm-bridge`.
